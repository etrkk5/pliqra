## Commercial offerings

Paid deployment assistance, training, maintenance and support can be offered separately from the software license. The repository license itself grants no support entitlement, availability commitment or production certification. Any such commitment requires a separate agreement.

Future commercial modules, if introduced, must be separately identified and licensed. No existing module in this repository is designated proprietary by this document. Code already released under Apache-2.0 remains available under that grant; a future paid offering does not revoke those rights.

## Distribution

Source archives include LICENSE and NOTICE. The Docker build copies both into `/app` and declares the SPDX identifier `Apache-2.0` in its OCI license label. Dependencies installed in the image keep their own package license files and notices.

The existing `v2.1.0-rc.2` tag and image predate this license addition. They are not rebuilt or retagged by this change; subsequent builds include these files and metadata. The canonical license for this repository is [LICENSE](../LICENSE).
